# Deep Research Skill Dependencies
#
# Core: Python 3.9+ standard library only. No pip install needed.
#
# Search is provided by Hermes MCP servers — no external CLI required:
#   - obsidian-grimoire MCP (local wiki, searched first)
#   - Kagi MCP (primary web search)
#   - Exa MCP (semantic/neural search)
#
# Optional tools (not Python packages):
#
# obsidian-headless — Obsidian Sync for the ~/research vault
#   Invoke:  env PATH="$HOME/.local/bin:$PATH" npx --package=obsidian-headless --yes -- ob sync
#   Requires Node.js 22+; the env PATH prefix pins ~/.local/bin/node (v22) ahead of
#   ~/.nix-profile/bin/node (v24) so native modules build/load against the same ABI
#
# weasyprint — PDF generation from HTML reports
#   Install: pip install weasyprint   (user-level; or use uvx)
#   Used by: reference/html-generation.md (Phase 8 PDF output)
#
# verify_pdf_text.py — PDF text-layer verification (scripts/)
#   Stdlib only. Uses pypdf if installed, else falls back to pdftotext (poppler).
#   Install one of: pip install pypdf  OR  apt install poppler-utils
